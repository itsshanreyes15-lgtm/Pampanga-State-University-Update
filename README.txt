HOW TO RUN BABYYLATTT'S BIRTHDAY WEBSITE

1. Extract all files from this ZIP into one folder.
2. Add your two songs into the SAME folder, named exactly:
     bgsong.mp3         (background song; starts after the article and loops)
     envelopsong.mp3    (plays when the envelope is opened)
   (.m4a, .wav and .ogg also work if you prefer those.)
3. Open index.html in Chrome/Edge, or use VS Code Live Server.
4. Read through the article with three Next clicks; the background music starts when the password screen appears.
5. Password: 062125

Tip: browsers may block audio until your first interaction with the page.
To change the lyrics that appear while the envelope song plays, edit the
LINES list in index.html (t = seconds into the song).
